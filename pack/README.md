# Steady Kit Coping Tools Pack

Printable and offline companions to the Steady Kit web tools.

## What’s inside

| File | Purpose |
|------|---------|
| `DISCLAIMER.md` | Hard safety fence — read first |
| `ADULT_GUIDE.md` | How to use the tools as an adult (18+) |
| `SETUP.md` | How to open the web app offline / locally |
| `worksheets/` | Printable coping worksheets (PDF-friendly HTML / Markdown) |

## Quick start

1. Read `DISCLAIMER.md`.
2. Skim `ADULT_GUIDE.md`.
3. Print worksheets from `worksheets/` (open in a browser → Print).
4. Optional: open the Steady Kit web app locally (see `SETUP.md`).

## Brand

**Steady Kit** — faceless South African wellness tools. COI-safe. Not therapy.
