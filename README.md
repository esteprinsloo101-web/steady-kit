# Steady Kit

Faceless South African **wellness / psychological tools** web app for adults who feel down.  
**Not therapy. Not counselling. Not a crisis service.**

## Live / local

Open `index.html` or serve the folder:

```bash
python3 -m http.server 8765
```

## Modules

1. Mood check-in (localStorage history + chart)  
2. Coping deck (5-4-3-2-1, box breathing, urge surfing, kind self-talk)  
3. Micro-tasks / behavioural activation  
4. Music mood links (YouTube / Spotify search — third-party disclosed)  
5. Voice encouragement (Web Speech API)  
6. Private journal (local only)  
7. Soft CTA → Gumroad pack (R149, placeholder until publish)

## Safety

- Sticky crisis banner + `crisis.html` (SADAG 0800 567 567, findahelpline.com)  
- Disclaimer on every surface  
- Adults 18+ · no child data  
- No clinical claims · no therapist AI chat
